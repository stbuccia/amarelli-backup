# 1. What you need

Buy or find these parts before you start. Prices change, so this is only a rough guide

## Main parts

| Photo | Part | Notes | Link | Price |
|---|---|---|---|---|
|| Raspberry Pi Zero W / 2W | The brain of the box. The older Zero W works too, but is slower. | | |
|| microSD card for the Pi | 16 GB or more. This holds the system, not your photos. | | |
|| Waveshare 2.13" e-Paper HAT (V4) | The screen. It must be the **V4** version. Other versions use a different driver. | | |
|| External microSD reader (SPI) | Reads the camera card. It must be an SPI reader, not a USB one. You push the camera card in here. | | |
|| WS2812B LED strip | 10 LEDs. Also sold as "NeoPixel". | | |
|| Reed switch | A magnet switch. It tells the box when the lid is shut. | | |
|| 4 push buttons | For the menu on the box. | | |
|| An Amarelli liquorice tin | The case. Any small box works, but the tin is the point. | | |

## Needed but not included in price

- Power supply micro-USB, 5V 2 A or more
- Welder
- Multimeter
- Caliber
- Glue
- 3d printed models

When you have the parts, go to [Wiring and assembly](02-wiring-and-assembly.md).
